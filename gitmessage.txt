middleware no Express. 
Middleware é basicamente uma função que fica 
“no meio do caminho” entre a requisição e a resposta, 
podendo interceptar, modificar ou validar antes de 
chegar na rota final.

Estrutura de pastas do projeto
EXPRESS-API/
 api/
 ├── dist/                # código compilado (se usar TypeScript)
 ├── node_modules/        # dependências
 ├── requisicoes/         # seus arquivos .http para testar requisições
 └── src/
      ├── controllers/    
      │     ├── filmesController.ts
      │     ├── infoController.ts
      │     └── autenticacao/
      │            └── authController.ts   # função de login
      ├── middlewares/
      │     └── authMiddleware.ts          # validação do token JWT
      ├── dados/
      │     └── filmes.ts                  # dados em memória
      ├── model/
      │     └── filme.ts                   # definição de tipos
      ├── routes/
      │     ├── filmes.ts                  # rotas de filmes
      │     └── info.ts                    # rotas de info
      └── main.ts                          # ponto de entrada da aplicação


📌 Dicas para o fluxo de trabalho
Editar código → mexe nos arquivos (main.ts, middlewares, etc.).

Testar localmente → roda npm run dev e acessa as rotas no navegador.

Salvar progresso no Git

git add .

git commit -F gitmessage.txt

git push origin master
